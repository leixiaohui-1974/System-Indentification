# 数字孪生水力系统用户操作手册

## 概述

本手册为用户提供数字孪生水力系统的详细操作指南，包括系统安装、基本操作、高级功能和故障排除等内容。

## 系统简介

数字孪生水力系统是一套基于数字孪生技术的智能化水力系统仿真和监控平台。通过构建物理系统的数字化镜像，实现对水力系统的实时监控、故障诊断、参数辨识和优化控制。

### 主要功能

1. **实时仿真**: 基于物理模型的高保真仿真
2. **故障诊断**: 智能故障检测和预测性维护
3. **参数辨识**: 在线参数估计和模型更新
4. **可视化监控**: 2D/3D可视化界面
5. **远程控制**: 远程系统控制和调度
6. **数据分析**: 历史数据查询和分析

## 系统要求

### 硬件要求

- **CPU**: Intel i5或同等性能处理器
- **内存**: 最少8GB RAM（推荐16GB）
- **存储**: 最少20GB可用空间
- **显卡**: 支持OpenGL 3.3+的显卡
- **网络**: 稳定的网络连接

### 软件要求

- **操作系统**: Windows 10+/macOS 10.15+/Ubuntu 18.04+
- **浏览器**: Chrome 80+/Firefox 75+/Edge 80+
- **移动端**: iOS 12+/Android 8.0+

## 安装和启动

### 本地安装

1. **下载安装包**
   访问官方网站下载最新版本安装包

2. **安装系统**
   - Windows: 运行`.exe`安装程序
   - macOS: 拖拽应用到Applications文件夹
   - Linux: 解压`.tar.gz`文件到指定目录

3. **启动系统**
   - 桌面应用: 双击图标启动
   - 命令行: 运行`digital-twin-system`

### Docker安装

```bash
# 拉取镜像
docker pull digitaltwin/system:latest

# 运行容器
docker run -d -p 8000:8000 -p 3000:3000 digitaltwin/system
```

### Kubernetes部署

```bash
# 部署到Kubernetes集群
kubectl apply -f https://raw.githubusercontent.com/digitaltwin/system/main/k8s-deployment.yaml
```

## 基本操作

### 1. 系统监控

#### 查看系统状态

1. 点击左侧导航栏"系统监控"
2. 查看系统健康状态指标
3. 监控实时传感器数据
4. 观察参数估计值变化

#### 3D可视化

1. 点击"3D可视化"标签页
2. 使用鼠标拖拽旋转视角
3. 滚轮缩放视图
4. 点击组件查看详细信息

### 2. 数据管理

#### 查看历史数据

1. 点击左侧导航栏"数据管理"
2. 选择时间范围和传感器类型
3. 点击"查询"按钮
4. 查看数据图表和统计信息

#### 数据导出

1. 在数据查询结果页面
2. 点击"导出"按钮
3. 选择导出格式（CSV/Excel/JSON）
4. 保存文件到本地

### 3. 算法控制

#### 参数设置

1. 点击左侧导航栏"算法控制"
2. 修改算法参数值
3. 点击"保存"按钮
4. 重启相关服务使配置生效

#### 模型切换

1. 在算法控制页面
2. 选择目标模型类型
3. 点击"切换模型"按钮
4. 等待切换完成

### 4. 故障诊断

#### 实时故障检测

1. 点击左侧导航栏"故障诊断"
2. 查看当前故障状态
3. 分析故障原因和影响
4. 查看历史故障记录

#### 预测性维护

1. 在故障诊断页面
2. 查看维护建议
3. 设置维护计划
4. 跟踪维护执行情况

### 5. 仿真控制

#### 启动仿真

1. 点击左侧导航栏"仿真控制"
2. 设置仿真参数：
   - 仿真时长
   - 时间步长
   - 上游来流
   - 闸门开度
3. 点击"启动仿真"按钮

#### 控制仿真

1. 仿真运行中可执行：
   - 暂停/继续仿真
   - 调整参数
   - 注入故障
   - 重置仿真

### 6. 系统设置

#### 用户管理

1. 点击左侧导航栏"系统设置"
2. 选择"用户管理"标签页
3. 添加/编辑/删除用户
4. 设置用户权限

#### 系统配置

1. 在系统设置页面
2. 选择"系统配置"标签页
3. 修改系统参数
4. 点击"保存配置"按钮

## 故障排除

### 常见问题

#### 1. 无法登录系统

**问题现象**: 输入正确用户名密码仍无法登录

**解决方案**:
1. 检查网络连接是否正常
2. 确认系统服务是否启动
3. 重置密码或联系管理员

#### 2. 数据不更新

**问题现象**: 实时数据显示停止更新

**解决方案**:
1. 检查传感器连接状态
2. 重启数据采集服务
3. 查看系统日志定位问题

#### 3. 3D可视化卡顿

**问题现象**: 3D场景操作不流畅

**解决方案**:
1. 降低图形质量设置
2. 关闭不必要的可视化组件
3. 检查显卡驱动是否最新

#### 4. 仿真运行缓慢

**问题现象**: 仿真计算速度慢

**解决方案**:
1. 检查CPU和内存使用情况
2. 优化仿真参数设置
3. 启用GPU加速（如支持）

## 维护和升级

### 日常维护

#### 数据备份

```bash
# 备份数据库
pg_dump digital_twin > backup_$(date +%Y%m%d).sql

# 备份配置文件
tar -czf config_backup_$(date +%Y%m%d).tar.gz /etc/digital-twin/
```

#### 系统清理

```bash
# 清理日志文件
logrotate /etc/logrotate.d/digital-twin

# 清理临时文件
rm -rf /tmp/digital-twin-*
```
