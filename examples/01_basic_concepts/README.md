# 01 基础概念介绍

## 概述

本示例介绍数字孪生水力系统的核心概念和架构设计，帮助初学者理解系统的整体框架。

## 核心概念

### 1. 数字孪生双模型架构

数字孪生系统采用双模型架构：

- **模型A（高保真模型）**：基于有限体积法（FVM）的精确物理仿真
- **模型B（轻量化孪生模型）**：基于积分时滞（ID）模型的简化版本

### 2. 系统层次结构

```
┌─────────────────┐
│   可视化层      │
├─────────────────┤
│  控制与管理层   │
├─────────────────┤
│ 诊断与辨识层    │
├─────────────────┤
│    模型层       │
├─────────────────┤
│  数据生成层     │
└─────────────────┘
```

### 3. 关键组件

- **传感器仿真器**: 模拟真实传感器数据
- **数据预处理器**: 清洗和过滤原始数据
- **故障检测器**: 识别传感器故障
- **系统辨识器**: 在线更新模型参数
- **仿真管理器**: 协调整个系统运行
